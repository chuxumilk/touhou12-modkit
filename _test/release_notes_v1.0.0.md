# TH12 魔改工具 v1.0.0

《东方星莲船》(TH12) 的**格式库 + 网页版魔改工具**：把 `th12.dat` / `th12c.dat`
里的贴图、音乐、对话、音乐室评论以及任意归档文件提取出来，改完再写回去。
纯 Python 实现，本地 Web 界面，日文版与汉化版都支持。

> ⚠️ **本仓库与附件都不含游戏本体**，请自备一份正版《东方星莲船》。
>
> 🛑 **改文件前请先完全退出游戏**。游戏运行时它的数据文件往往仍可写入，
> 硬写会直接导致**游戏文件损坏**（不是普通的"文件被占用"）。
> 工具已做预检查，检测到游戏在运行会拒绝写入。

## 快速上手

1. 启动后浏览器会打开 `http://127.0.0.1:8765/`
2. 点右上角 **⚙ 设置目录** → 点 **「选文件…」** 选你游戏目录里的
   `th12.dat` 或 `th12c.dat`（也可以选目录，或点扫描出来的候选目录）
3. 改贴图 / 音乐 / 对话 → 页面底部出现「有 N 项修改待保存」→
   点 **「保存到游戏…」** 才真正写盘（保存前会自动备份）

> 工作流是「先暂存、后保存」：所有改动都先进暂存区，确认无误再一次性写入。

## 本次内容

### 主要功能

- **贴图**：浏览全部 ANM 并实时预览，按贴图名全局搜索，PNG 导入导出
  （BGRA8888 / RGB565 / A4R4G4B4 / GRAY8），整个 ANM 一键导出 ZIP
- **音乐**：18 首 BGM 试听、导出 WAV、替换（自动转 16bit/立体声/44100Hz）、
  设置循环点，最后重建 `thbgm.dat`
- **对话**：按条目编辑 `.msg` 并标出说话人，可导出翻译文档再导入并逐条预览改动
- **批量导入**：按文件名自动识别，合成图按各条目 x/y 自动切分回填
- **任意文件**：`.ecl` / `.sht` / `.std` / `.rpy` 等导出与替换
- **备份 / 还原**：首次修改前自动备份，支持单个还原、下载、全部还原
- **日志**：记录全部写操作，可查看 / 导出

### 数据安全

- 归档写入为**原子操作**：先写临时文件、写完自检（条目表自洽 + 抽查解压），
  不通过就放弃写入、保留原文件
- **写盘前检查游戏进程**，检测到 `th12.exe` / `th12c.exe` 在运行就拒绝写入
- 设置目录时会对归档做**体检**，能发现以前被写坏的文件并说明原因
- 音乐数据读不出来时降级为提示，贴图 / 对话仍可正常使用

### 验证情况

- 归档解包与官方 `thdat` 逐字节一致（日文版 180/180、汉化版 179/179）
- 贴图解码与官方 `thanm` 导出的 PNG 逐像素一致（4 种像素格式）
- 空操作重建 `thbgm.dat` 与原文件 MD5 相同
- 对话解析 → 重建与原文件逐字节一致（Shift-JIS / GBK）

## 已知限制

- 音乐只支持未压缩 PCM WAV 上传
- 贴图改尺寸后，引用它的精灵位置可能需要另行调整
- 重建 `thbgm.dat` 需要约 1 倍文件大小的临时空间
- `.ecl` 弹幕脚本只支持原样替换，没有可视化编辑
- Web UI 只监听本机，未做多用户与鉴权
