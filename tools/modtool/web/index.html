    替换曲目：上传 WAV（自动转成 16bit / 立体声 / 44100Hz）。 循环点 = 引子长度（秒）：前这么多秒只播一次，之后一直在该处循环； 0 表示整首从头循环。 实现方式是改音频 —— th12.exe 播放时只把整块音频反复循环， 并不读 thbgm.fmt 里那个循环点字段，所以保存时会把引子复制到末尾 （拼接处是硬切，乐器会断，总长也会多出引子那么长）。 所有修改都会先暂存，点页面底部的「保存到游戏」才会真正写入 （重建 thbgm.dat 约 400MB，需要一点时间）。
