    BGM 曲目

    替换曲目：上传 WAV（自动转成 16bit / 立体声 / 44100Hz）。 循环点 = 曲目内循环回到的位置（秒），0 表示从头循环。 修改先暂存，点“应用修改”才会重建 400MB 的 thbgm.dat。

    #曲目时长循环点 状态试听操作

      请选择左侧的对话文件

      归档文件

      可以把任意文件（.ecl 弹幕脚本、.sht 自机、.std 关卡、.rpy 录像等） 导出备份或原样替换回去。替换前会自动备份原 .dat。

      文件名类型原始大小存储大小操作

      musiccmt.txt（音乐室曲目评论）

      格式：@bgm/曲目名 下一行是评论文字。 汉化版按 GBK 保存，日文版按 Shift-JIS 保存。

      操作日志

      记录所有写操作（替换贴图 / 保存对话 / 重建音乐 / 还原备份…）， 同时保存在 tools/modtool/logs/modtool.log（JSON Lines）。

      备份 / 还原

      工具在第一次修改某个文件前会自动生成 *.modtool.bak（保留最原始的版本）。点“还原”会把备份写回游戏。
