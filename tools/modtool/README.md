# 东方星莲船 魔改工具

一个本地网页版（Web UI）的《东方星莲船》(TH12) 魔改工具，可以修改
**贴图、音乐、对话文本、音乐室评论，以及归档里的任意文件**。

日文版（`th12.dat`）和汉化版（`th12c.dat`）都支持，修改前会自动备份。

---

## 一、怎么用

双击 **`启动魔改工具.bat`**，浏览器会自动打开 `http://127.0.0.1:8765/`。

也可以手动启动：

```bat
python tools\modtool\server.py
```

可选参数：

| 参数 | 说明 |
| --- | --- |
| `--port 8765` | 指定端口 |
| `--no-browser` | 不自动打开浏览器 |
| `--game-dir "路径"` | 指定游戏目录（默认是 `game/[th12] 东方星莲船 (汉化版+日文版)`） |

> 修改前请先**关闭游戏**，否则文件被占用会写入失败。

### 换成另一份 TH12 游戏文件

工具支持任意目录，只要那个目录里有游戏数据文件即可：

- 最少需要 `th12.dat`（日文版）**或** `th12c.dat`（汉化版）
- 想改音乐还需要 `thbgm.dat`（约 400MB）
- `th12.exe` / `th12c.exe` 不是必须的，但**有的话可以直接在网页里点“启动游戏”**

四种用法任选：

1. **网页里设置**（推荐）：右上角 **⚙ 设置目录** → 填路径（或点“浏览…”选文件夹，
   也可以直接点下面列出的候选目录）→ 应用。
   设置会保存到 `tools/modtool/config.json`，下次启动自动记住。

2. **把游戏文件夹直接拖到 `启动魔改工具.bat` 上**，会自动以该目录启动。

3. **命令行指定目录**：
   ```bat
   python tools\modtool\server.py --game-dir "D:\我的游戏\th12"
   ```

4. **把游戏文件放进默认目录**：
   `game/[th12] 东方星莲船 (汉化版+日文版)/`

### 网页里启动游戏

右上角 **▶ 启动游戏** 按钮会运行当前版本对应的
`th12.exe` / `th12c.exe`（工作目录设为游戏目录）。

> 改完贴图/音乐后，先关掉游戏再改，改完点“启动游戏”即可验证。
> 修改期间游戏必须处于关闭状态，否则会提示“文件被占用”。

> 注意：工具是按 **TH12** 的参数写的（归档加密参数、thbgm.fmt 结构等）。
> 换成 th11 / th13 等其他作品的 .dat 无法解析。

## 二、功能

### 1. 贴图（.anm）
- 左侧列出归档里的 `.anm` 文件，点开后可看到里面所有贴图的**实时预览**
- 支持 PNG **导出 / 替换**；替换时自动按原格式（BGRA8888 / RGB565 /
  A4R4G4B4 / GRAY8）重新编码写回
- 支持改变贴图尺寸（一般建议保持原尺寸，否则精灵坐标可能需要一起调整）

### 2. 音乐（thbgm.dat + thbgm.fmt）
- 列出 18 首 BGM（时长、循环点）
- 支持在线**试听**、导出 WAV、上传 WAV 替换
- 上传的音频会自动转换成游戏需要的 **16bit / 立体声 / 44100Hz**
- 可设置**循环点**（秒）
- 修改先暂存，点“应用修改到游戏”才会重建 `thbgm.dat`（约 400MB，需要等几秒到几十秒）

### 3. 对话（.msg）
- 按条目展示每条对话的文本，**每句前面标出说话人**：
  `自机`（博丽灵梦 / 雾雨魔理沙 / 东风谷早苗）、
  `敌机`（按关卡显示 Boss 名，如「云居一轮」）、`旁白`
- 文件名自动解析出 **角色 / 关卡 / Boss / 场景**，显示在标题栏
- 可直接在网页里编辑并保存；日文版按 Shift-JIS、汉化版按 GBK 编码
- **导出文档**：导出一份 UTF-8 文本，交给翻译/校对
  （格式 `[条目.指令] [说话人] 文本`，用任何文本编辑器改都行）
- **导入文档**：把改好的文档传回来，先**弹窗预览每一处改动**（旧 → 新），
  确认后才写入；无法识别的行会跳过，用了目标编码表示不了的字符会警告
- 非文本指令（演出、等待、立绘等）原样保留

### 4. 批量导入（按文件名自动替换）
「批量导入」页可以直接**选择一个文件夹**（或一堆文件），工具按文件名自动识别：

| 文件名示例 | 识别为 |
| --- | --- |
| `face02no.png` | **按贴图名匹配**（推荐）：找到游戏里所有叫 `face02no.png` 的贴图；尺寸等于“合成画布”时自动按各条目的 x/y 切分回填 |
| `ascii.anm_0.png` | `ascii.anm` 的第 0 张贴图 |
| `etama@bullet@0.png` | `bullet.anm` 的第 0 张贴图（thanm 风格） |
| `st01_00a.txt` | `st01_00a.msg` 的对话文档（列表里显示“将修改 N 句”，可点“预览改动”） |
| `stage01.ecl`、`st01_00a.msg` … | 与归档同名，原样替换 |
| `musiccmt.txt` | 音乐室评论 |

**关于合成图**：游戏里同一张贴图可能被拆成好几块（例如
`face02no.png` 在 `stgenm02.anm` 里是 337×256 + 337×128 + 337×32 三块，
按 y 偏移叠成 337×416）。如果你手上的 PNG 正好是 337×416，
工具会自动按每块的 x/y 切回去；如果只是其中一块的尺寸，就只替换那一块。

识别不了的文件会标成“未识别”并自动跳过。确认无误后点「应用全部」，
每个归档只写一次，并自动备份。

> 首次构建“贴图名索引”需要解压全部 .anm（约 30 秒，后台自动预热），
> 之后会缓存到 `tools/modtool/staging/`，再导入就是秒级。

### 5. 任意文件
- 归档里所有文件（`.ecl` 弹幕脚本、`.sht` 自机、`.std` 关卡、`.rpy` 录像…）
  都可以导出备份 / 原样替换

### 6. 音乐室评论
- 直接编辑 `musiccmt.txt`

### 7. 日志
- 记录所有写操作（替换贴图、保存对话、导入文档、重建音乐、还原备份…）
- 网页「日志」页可查看 / 刷新 / 清空 / 导出
- 同时保存在 `tools/modtool/logs/modtool.log`（JSON Lines，可脚本分析）

### 8. 备份 / 还原
- 第一次修改某个文件前会自动生成 `xxx.modtool.bak`（保留最原始版本）
- 随时可以在“备份 / 还原”页把原文件写回去

## 三、目录结构

```
东方魔改/
├─ thtk/                     # 核心格式库（纯 Python）
│   ├─ crypto.py             #   ZUN 流密码（加密/解密）
│   ├─ lzss.py               #   ZUN 自定义 LZSS 压缩
│   ├─ archive.py            #   THA1 归档 (.dat) 读写
│   ├─ anm.py                #   ANM 贴图解析 / 替换
│   ├─ bgm.py                #   thbgm.dat / thbgm.fmt
│   └─ msg.py                #   .msg 对话
├─ tools/modtool/
│   ├─ server.py             # Web 后端（本地 HTTP 服务）
│   ├─ web/                  # 网页前端
│   ├─ staging/              # 音乐修改暂存
│   └─ 启动魔改工具.bat
└─ _recon/                   # 格式逆向调研记录（可删）
```

依赖：Python 3.7+、`Pillow`、`numpy`（转换贴图用）。

```
pip install pillow numpy
```

## 四、格式说明（给想继续折腾的人）

### THA1 归档（th12.dat / th12c.dat）
```
0x00  16 字节头（整体加密）: "THA1" + list_size + list_zsize + entry_count
      三个字段分别加常量 123456789 / 987654321 / 135792468
0x10  条目数据（每条按文件名和 &7 选一组密码参数加密）
末尾  条目表（LZSS 压缩 + 加密）
条目表项: name(补零到 4 字节) + u32 offset + u32 size + u32 0
```

### ANM 贴图
TH12 使用 `anm_header11_t`（version=7），条目通过 `nextoffset` 串成链，
贴图数据在 `THTX` 块里：

| format | 含义 | 每像素 |
| --- | --- | --- |
| 1 | BGRA8888 | 4 字节 B,G,R,A |
| 3 | RGB565 | 2 字节 LE，R5<<11 \| G6<<5 \| B5 |
| 5 | A4R4G4B4 | 2 字节 LE，A4<<12 \| R4<<8 \| G4<<4 \| B4 |
| 7 | GRAY8 | 1 字节灰度 |

### BGM
`thbgm.dat` 头部 16 字节（`ZWAV`），之后是连续的 16bit 立体声 PCM；
`thbgm.fmt` 放在归档里，每条 0x34 字节：

```
0x00 name[16]
0x10 u32 offset    在 thbgm.dat 中的偏移
0x14 u32 preload   预读字节数
0x18 u32 loop      循环起点（相对 offset）
0x1C u32 end       长度
0x20 WAVEFORMATEX 16 字节
0x30 u32 zero
```

### .msg 对话
```
u32 entry_count
entry_count × (i32 offset, i32 extra)
指令流: u16 time, u8 type, u8 length, u8 data[length]
文本 = type 17，数据用滚动密钥 XOR 混淆（key=0x77, +7, +16）
```

## 五、已知限制

- 音乐只支持未压缩 PCM WAV 上传（其他格式请先转成 WAV）
- 贴图改尺寸后，引用它的精灵显示位置可能需要另行调整
- 重建 `thbgm.dat` 需要约 1 倍文件大小的临时空间
- 弹幕脚本（.ecl）只支持原样替换，没有可视化编辑
